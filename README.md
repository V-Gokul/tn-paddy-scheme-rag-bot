# Tamil Nadu Farmer Scheme Assistant

A RAG (Retrieval-Augmented Generation) chatbot that answers questions about Tamil Nadu government paddy/agriculture schemes — subsidies, eligibility, and contact officers — built with LangChain, OpenAI, and ChromaDB.

The repo intentionally includes **two versions of the RAG chain** side by side, for comparison/learning:

| Scenario | Chain | Apps |
|---|---|---|
| **Stateless** — each question answered independently, no memory | [`src/chains/stateless_chain.py`](src/chains/stateless_chain.py) | [`apps/cli_stateless.py`](apps/cli_stateless.py), [`apps/streamlit_stateless.py`](apps/streamlit_stateless.py) |
| **Conversational** — follow-ups like *"who do I contact for it?"* are rephrased using chat history before retrieval | [`src/chains/conversational_chain.py`](src/chains/conversational_chain.py) | [`apps/streamlit_conversational.py`](apps/streamlit_conversational.py) |

Both chains share config (model names, chunk size, retriever `k`) from [`src/config.py`](src/config.py), so the only difference between them is the memory logic itself.

## How it works

```
src/scraper.py  --scrapes-->  data/processed/tn_farmer_schemes.md
                                        │
                                        ▼
src/ingestion.py  --chunks + embeds-->  data/chroma_db  (ChromaDB vector store)
                                        │
                                        ▼
src/chains/*.py  --retrieves top-k chunks + calls OpenAI-->  answer
                                        │
                                        ▼
                          apps/*.py  (CLI or Streamlit UI)
```

1. **Scrape** — [`src/scraper.py`](src/scraper.py) uses Playwright to render the [TNAU Agritech Schemes page](https://agritech.tnau.ac.in/expert_system/paddy/Schemes.html) and BeautifulSoup to extract scheme tables into a clean Markdown file.
2. **Ingest** — [`src/ingestion.py`](src/ingestion.py) splits that Markdown into ~800-character chunks and embeds them with OpenAI's `text-embedding-3-small`, storing the vectors in a local ChromaDB at `data/chroma_db/`.
3. **Chain** — at query time, the retriever pulls the top-8 most relevant chunks for the question and passes them as context to `gpt-4o-mini`, which is prompted to answer only from that context (scheme name, benefits, eligibility, contact officer).
4. **App** — the chain is wrapped in either a CLI loop or a Streamlit chat UI. The conversational version additionally rephrases follow-up questions into standalone questions using the chat history before retrieval.

## Install

**Prerequisites:** Python 3.10+, an [OpenAI API key](https://platform.openai.com/api-keys).

```bash
git clone https://github.com/V-Gokul/tn-paddy-scheme-rag-bot.git
cd tn-paddy-scheme-rag-bot

python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # macOS/Linux

pip install -r requirements-dev.txt   # or requirements.txt if you don't need to run tests
playwright install chromium           # only needed if you'll run the scraper
```

Set up your environment file:

```bash
cp .env.example .env
```

Then open `.env` and fill in your key:

```
OPENAI_API_KEY="sk-..."
```

## Run

A pre-built vector database is **not** included in the repo (it's gitignored — see [Notes](#notes)), so the first run needs to build it:

```bash
# 1. Scrape the source data (skip if data/processed/tn_farmer_schemes.md already exists)
python -m src.scraper

# 2. Chunk + embed into ChromaDB (run again any time the source data changes)
python -m src.ingestion
```

Then run any of the three apps:

```bash
python apps/cli_stateless.py                     # CLI chat, no memory
streamlit run apps/streamlit_stateless.py         # Web chat, no memory
streamlit run apps/streamlit_conversational.py    # Web chat, remembers earlier turns
```

The Streamlit apps open automatically in your browser at `http://localhost:8501`.

## Tests

```bash
pytest tests/ -v
```

- `tests/test_ingestion.py` checks the scraped Markdown chunks correctly (no API calls).
- `tests/test_chains.py` calls the real OpenAI API and is skipped automatically if `OPENAI_API_KEY` isn't set.

## Notes

- `.env` holds secrets and is gitignored — never commit it. `.env.example` documents the required variables.
- `data/chroma_db/` is generated by `src.ingestion` and gitignored; regenerate it locally rather than committing the binary DB.
- Config (model names, `CHROMA_PATH`, retriever `k`, temperature) can be overridden via environment variables — see [`src/config.py`](src/config.py).
